Track 1: Community Leaders and Core Team Members

Goal: Run a student-led cybersecurity community well: communications, events, partnerships, people and security hygiene, with enough technical literacy to lead credibly.

Version A

	•	Digital Awareness
	•	Digital Safety and Security Awareness
	•	AI foundation: Introduction to Modern AI → Core Generative AI Skills → Prompt Like an Engineer
	•	Optimizing Generative AI
	•	Create Digital Content, Communicate and Collaborate Online
	•	Engaging Stakeholders for Success
	•	Discovering Entrepreneurship → Launching a Business Venture (sponsorship, budgets, sustaining the community)
	•	Build Your Resume with AI (so leaders can coach members)
	•	Creating Compelling Reports (sponsor reports, impact reports, event write-ups)
	•	AI Power User Launchpad (productivity workflows for a small volunteer team)

Track 8: Cloud Security

Goal: Secure cloud workloads, identities and configurations.

Do AWS hands-on labs every week, through every phase.

Phase 1: Foundations

	1.	AI foundation + Optimizing Generative AI(https://www.netacad.com/courses/ibm-foundations-understanding-ai?courseLang=en-US&instance_id=bdd4b78f-4660-4e68-ab36-d2db88eb2854)
	2.	Cisco Introduction to Cybersecurity (https://www.netacad.com/courses/introduction-to-cybersecurity?courseLang=en-US&instance_id=f908c6b5-7cd2-466d-a4ba-a19de81b5d7a)
	•	Resource: Cisco NetAcad (free)
	3.	Cisco CCNA 1 / Networking Basics
	•	Resource: Cisco NetAcad (free)

Phase 2: Core Technical Skills

	4.	Linux: Cisco Linux Essentials (https://www.netacad.com/courses/linux-1?courseLang=en-US&instance_id=007f4d3d-90aa-4d9b-a129-9fe26c8f4223)
	•	Resource: Cisco NetAcad (free)
	5.	Python: Cisco Python Essentials 1 & 2
	•	Resource: Cisco NetAcad (free)
	6.	Cisco CyberOps Associate (Security+ substitute, with a real cert at the end) (https://www.netacad.com/trainings/cyberops-associate?courseLang=en-US&instance_id=f188ebad-c7e4-499d-9de9-fb732a1553a7)
	•	Resource: Cisco NetAcad
	7.	Windows / Active Directory: search "Active Directory fundamentals"
	•	Resource: Microsoft Learn (free), https://learn.microsoft.com
	8.	Virtualization and containers: search "Introduction to containers"
	•	Resource: NetAcad or IBM SkillsBuild (free)

Phase 4: Specialization

	11.	AWS Security Specialty: only after SAA
	•	Resource: AWS Skill Builder
